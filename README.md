# Waterlife — ABYSS: Última señal

Juego de supervivencia y exploración submarina en 3D, creado con Three.js.

## Jugar

Descarga `ABYSS-v05.html` y ábrelo directamente en Edge, Chrome o Firefox. Es un único HTML autocontenido y no necesita conexión a Internet.

Pulsa **Comenzar** y después **Haz clic para controlar al buceador**. El juego requiere captura real del ratón; algunos visores integrados no la permiten. **Esc** libera el cursor y abre el menú.

## Controles

- **WASD / flechas**: nadar.
- **Ratón**: mirar.
- **C / Espacio**: descender / ascender.
- **Clic izquierdo**: excavar o pescar.
- **1 / 2**: herramienta de extracción / lanza.
- **E**: abrir el taller junto a la balsa.
- **F**: comer pescado.
- **Esc**: pausa y opciones de pantalla completa.

## Objetivo

Recoge materiales, pesca, mejora los cinco equipos y recupera la caja negra a −100 metros. Regresa a la balsa para transmitir la señal de socorro.

Incluye cuatro zonas, oxígeno, energía, mochila, túneles naturales y guardado local en el navegador. Las profundidades están comprimidas para esta aventura ficticia.

## Versión

La versión actual es **0.5**, con captura real del ratón y taller separado del clic izquierdo. Three.js se distribuye integrado en el HTML con su aviso de licencia.
